# 谷子消费工作台（独立版）

个人谷子消费追踪工作台的**独立部署版**——单文件 HTML、零外部依赖、数据存本设备浏览器（IndexedDB），不依赖任何平台。

## 使用

1. 打开 https://suki12123.github.io/guzi-workbench/
2. 首次使用：左下角「导入恢复」→ 选择你的备份 JSON（如 `独立版初始数据.json`），全部历史数据即导入本设备
3. 之后正常记录即可，数据自动保存在本设备浏览器中

## 数据安全

- 数据只存在**你自己浏览器**的 IndexedDB 里，不上传任何服务器
- 换设备 / 清浏览器数据 = 数据丢失，请**定期点「导出备份」**保存 JSON
- 本仓库只包含页面代码，**不含任何个人数据**

## 特性

- 概览统计 / 消费记录 / 转出回本 / 待开场贩四视图
- 搜索、多维筛选、表头排序、详情就地编辑
- 状态胶囊快改、付款截图（本地压缩 base64 存储）
- 本地 IndexedDB 持久化 + 多标签页自动同步 + 导入/导出备份
- 手机 / 电脑自适应

## 技术说明

单文件 HTML（约 185 KB），全部 CSS/JS/图标内联；存储层为本地 IndexedDB 适配器（实现 query/add/update/delete/getSchema/uploadImage/onUpdated 协议），后续可替换为远端后端实现多设备同步。
